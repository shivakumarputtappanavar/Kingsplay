## ✨ Features

- 🎵 **Online and offline music** in one app
- 🧭 **5 easy tabs:** Home, Explore, Search, Library, Settings
- 🌈 **Kings themes:** Classic, Neon, Ocean, Sunset, Emerald, Rose, Midnight
- 💧 **Liquid glass** bottom bar and mini player
- 🌊 **Liquid glow** effect you can customize
- 💿 **Player styles:** Normal, Album cover, Vinyl, Turntable
- ⏯️ **Premium player** with round glass buttons and smooth animations
- 👑 **3 app logos** with their own startup sounds
- 🎬 **Animated intro** in your theme colors
- 💭 **Your own Home thought:** write any line you like
- ⚡ **60 Hz / 120 Hz** smooth display option
- 📝 Synced lyrics, sleep timer, downloads, and more
